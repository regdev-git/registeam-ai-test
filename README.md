# RegisTeam — AI Landing Page

Односторінковий лендинг цифрової агенції RegisTeam для послуги створення
AI Landing Page. Темна монохромна стилістика з червоним акцентом, українська
мова, чотири кейси зі скриншотами.

## Структура

```
index.html      готова сторінка — один самодостатній файл, нічого не тягне ззовні
build.py        збирає index.html із src/ та assets/
src/page.html   вихідник розмітки, стилів і скриптів (з плейсхолдерами)
src/fonts.css   Unbounded + Inter Tight, підмножини latin/cyrillic/cyrillic-ext
assets/keys*.jpg  макети кейсів
```

`index.html` зібраний, тож його можна відкрити або задеплоїти напряму —
наприклад увімкнути GitHub Pages для гілки `main`.

## Збірка

```bash
python3 build.py
```

Скрипт підставляє вміст `src/fonts.css` і чотири зображення в `src/page.html`
як data URI та пише результат у `index.html`. Правки вносяться **у `src/page.html`**,
а не в `index.html` — останній перезаписується при кожній збірці.

Чому все вбудоване одним файлом: сторінка розрахована на середовище, яке блокує
зовнішні запити (CSP), тож ані шрифти з CDN, ані окремі файли зображень
підключити не можна.

## Що всередині

- **Перший екран** — тріангуляційна ґратка на Canvas 2D: вершини дрейфують,
  трійки в межах радіуса утворюють грані, курсор розштовхує поле й підсвічує
  грані під собою
- **Другий екран** — розліт трикутників, прив'язаний до позиції секції у вікні,
  тож програється вперед при скролі вниз і назад при скролі вгору
- **Блок послуги** — хвильове поле точок у перспективі та картки з ефектом
  liquid glass
- **Процес** — номери кроків розгоряються неоном у три стадії
- **Кейси** — макети в блоках із пропорцією 3:2 без обрізання
- **Тарифи** — вибір пакета підставляє бюджет у форму брифу
- **Контакти** — форма формує лист через `mailto:`

Анімації поважають `prefers-reduced-motion`: у цьому режимі canvas малює один
статичний кадр, а переходи вимикаються.
